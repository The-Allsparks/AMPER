# Glossary

| Term | Meaning |
|------|---------|
| **SelectedMotorsCurrentAmps** | Sum of VALID currents for motors AMPER is observing — not FRC PDH total current. |
| **Current** | Charge flow (amperes); correlates with motor torque and wiring loss. |
| **Power** | \(P \approx V \cdot I\); rate of energy use. |
| **Resistance** | Opposition to current; wiring and connectors add resistance. |
| **Internal resistance** | Battery’s effective series resistance; rises with age/temperature/SoC extremes. |
| **Voltage sag** | Drop in terminal voltage under load. |
| **Brownout** | Loss of reliable control-system operation under low voltage (platform-specific symptoms). |
| **Stall current** | High current when a motor cannot turn against load. |
| **Back EMF** | Voltage generated by a spinning motor opposing applied voltage. |
| **PWM** | Rapid on/off switching creating an average output voltage (Hub motor drivers). |
| **Slew rate** | Limit on how fast a command may change. |
| **Hysteresis** | Different enter/exit thresholds to prevent chatter. |
| **Feedforward** | Model-based command term (e.g., expected voltage for a motion) before feedback. |
| **Confidence** | Score in \([0,1]\) expressing estimate trust — never certainty. |
| **Power budget** | Planned allocation of available current/effort among functions. |

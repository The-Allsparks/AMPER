# Open an AMPER log in AdvantageScope

Required first-release visualization tool: **AdvantageScope**.

Sources (accessed **2026-08-17**):

- [AdvantageScope — log files / CSV import](https://docs.advantagescope.org/overview/log-files/)
- AMPER emits the official **table** layout. List layout is also generated by `exportAdvantageScopeListCsv()` for tests.

This walkthrough uses a Robot Controller capture. The committed [fixtures/amper-advantagescope-table.csv](fixtures/amper-advantagescope-table.csv) can be opened the same way without a robot.

## 1. Retrieve the log from the Robot Controller

1. Run an OpMode that calls `amper.observe()` each loop and `amper.stop()` in `stop()`.
2. On the Driver Station, stop the OpMode so AMPER flushes the file.
3. Connect the Control Hub over USB.
4. Android Studio **Device File Explorer** → `storage/emulated/0/FIRST/amper/`
   - Fallback: the FTC app’s `files/amper` directory (`getExternalFilesDir("amper")`).
5. Or from a laptop: `adb pull /sdcard/FIRST/amper/`
6. Copy `amper-session.csv` (and `amper-session.schema.json` if present) onto the computer that runs AdvantageScope.

Filenames are sanitized. A session exported as `amper test.csv` becomes `amper_test.csv`.

## 2. Open it in AdvantageScope

1. Install AdvantageScope from the [Mechanical Advantage documentation](https://docs.advantagescope.org/).
2. **File > Open Log(s)…** (or drag the CSV onto the window).
3. Choose the AMPER `.csv`. AdvantageScope treats the first column as `Timestamp` in **seconds**.
4. Fields appear under `/AMPER/...` in the left sidebar.

Do **not** open the internal diagnostic CSV (comment headers starting `# amper_csv_schema=`). That format is for `amper-analyze` tests, not AdvantageScope.

AdvantageScope documents that CSV export/reimport is lossy relative to WPILOG. Prefer the robot CSV or a desktop-converted `.wpilog` for archival.

## 3. Graph voltage, filtered voltage, motor current, and commanded effort

1. Open a **LineGraph** tab (or the default graph).
2. Drag these fields onto the graph (exact names):
   - `/AMPER/System/BusVoltageVolts`
   - `/AMPER/System/FilteredVoltageVolts`
   - `/AMPER/Motors/<motor>/CurrentAmps` (example: `/AMPER/Motors/frontLeft/CurrentAmps`)
   - `/AMPER/Motors/<motor>/Command`
3. Empty current cells mean that sample was not `VALID` (round-robin skip, stale, missing). They are not zero.
4. Optional: `/AMPER/System/MinimumVoltageVolts` for the match minimum.

See [field-selection.md](field-selection.md) for a sidebar checklist.

## 4. Add mechanism-start and warning fields

1. Drag `/AMPER/Events/Type` and `/AMPER/Events/Message` onto a graph or table.
2. Mechanism start/stop show as `STATE_TRANSITION` with messages `mechanism_start` / `mechanism_stop`.
3. Voltage warnings use `VOLTAGE_WARNING` and `/AMPER/System/PowerState` (for example `SEVERE_VOLTAGE_RISK`).
4. `/AMPER/Motors/<motor>/StallSuspected` is `true`/`false` (software suspicion, not a vendor stall bit).
5. Phase 0/1 mechanism effort: `/AMPER/Mechanisms/<name>/RequestedEffort` equals `GrantedEffort`, and `Constrained` is `false`.

## 5. Compare two battery sessions

1. Open the first match CSV (**File > Open Log(s)…**).
2. **File > Add New Log(s)…** and select the second match CSV (AdvantageScope log-files docs, accessed 2026-08-17; the menu may read “Add News Log(s)…”).
3. Graph the same `/AMPER/System/BusVoltageVolts` (and filtered voltage) from both logs.
4. Compare `/AMPER/System/MinimumVoltageVolts` and `/AMPER/Metadata/SessionId` so the two packs are not mixed up.
5. This is a visualization comparison, not Control Hub validation.

## 6. Export selected data from AdvantageScope

1. Select the fields you graphed.
2. **File > Export Data…** ([AdvantageScope export docs](https://docs.advantagescope.org/overview/log-files/export/), accessed 2026-08-17). CSV export is **lossy** compared with WPILOG.
3. For a WPILOG copy of an AMPER session, convert on a laptop — do not add WPILib JNI to the FTC app:

```text
./gradlew :amper-tools:generateWpiLogFixture
```

Or convert a retrieved CSV:

```text
./gradlew :amper-tools:classes
java -cp "amper-tools/build/classes/java/main;amper-core/build/classes/java/main" org.allsparks.amper.tools.AmperConvert --to-wpilog amper-session.csv amper-session.wpilog
```

On Linux/macOS, use `:` instead of `;` in `-cp`.

Then **File > Open Log(s)…** on the `.wpilog` in AdvantageScope.
